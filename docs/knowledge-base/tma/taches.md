# Les tâches projet

Une tâche projet est un travail planifié (une évolution, un chantier), distinct d'une demande de maintenance. Elle
est créée **par le Support**, pour **une application cliente** d'un client.

## Le cycle d'une tâche

| État | Ce qu'il veut dire |
| --- | --- |
| Brouillon | en préparation, **invisible** de l'application cliente |
| En cours | publiée : l'application cliente la voit et peut y participer |
| Terminée | achevée ; elle peut être facturée entièrement |
| Annulée | abandonnée, avec son historique |

**Publier** fait passer la tâche de Brouillon à En cours et l'envoie à l'application cliente. On peut aussi
programmer la publication (**Publication programmée**) : elle partira toute seule à cette date.

## Chez le Support

**Support › Tâches projet › Nouveau** : titre, application destinataire, projet, début et échéance prévue (tous
deux facultatifs), date de publication éventuelle, description et pièces jointes. Puis **Publier chez EDM**,
**Terminer** ou **Annuler**, et le temps passé dans le volet de droite, **Temps passé** (voir
[Le temps passé](#modal-tma.temps)).

## Dans l'application cliente

Les tâches publiées pour l'application apparaissent dans **Support › Tâches projet**, en lecture. On y participe par la
[chronologie](#modal-tma.chronologie) : messages, notes internes, images, réponses. On ne crée pas de tâche et on ne
change pas son état.
