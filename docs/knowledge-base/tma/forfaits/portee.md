# Un forfait pour un client ou une application

Un client peut avoir plusieurs applications (deux sites, par exemple). Son forfait peut être :

- **partagé** entre toutes ses applications : choisissez le **Client** et laissez **Application** vide. Le temps de
  toutes ses applications le consomme ;
- **propre à une application** : choisissez l'**Application**. Seul le temps de ses tickets le consomme.

Un client peut avoir les deux, ou un forfait par application : chaque forfait se suit séparément.

Le **Contrat** (facultatif) est un libellé pour s'y retrouver (« Contrat 2026 »), repris dans les alertes.
