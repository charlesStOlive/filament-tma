# Les seuils d'un forfait

À **80 %**, **90 %**, **100 %** (entièrement consommé) et **110 %** (dépassé) du volume d'une période, le
franchissement est **signalé une seule fois** : un courriel part aux adresses réglées pour cela, et l'application peut
y réagir autrement.

- Un seuil franchi ne se signale plus de la période, même si une saisie est corrigée puis refranchit le seuil.
- La période suivante, tout recommence.
- **Réinitialiser les seuils** (liste des forfaits) les rend de nouveau signalables pour la période **en cours** :
  après une erreur de saisie corrigée, par exemple.

Les seuils se règlent. Un dépassement **n'empêche pas** de saisir du temps, sauf si l'application est réglée pour.
