# Les projets

Un projet regroupe des [tâches projet](#modal-tma.taches) : il a un **titre**, une **application destinataire** et
autant de tâches qu'il en faut. Toutes ses tâches vont à cette application.

## Chez le Support

**Support › Projets › Nouveau** : le titre, l'application, une description (facultative). On peut aussi en créer un
au moment de créer une tâche, avec le **+** du champ **Projet**.

La fiche d'un projet montre ses tâches (une ligne ouvre la tâche ; **Nouvelle tâche** en crée une dans ce projet) et
son **temps passé**. Changer son titre le change aussi chez le client. Un projet sans tâche peut être supprimé.

## Dans l'application cliente

Les projets arrivent avec leurs tâches publiées, en lecture : **Support › Projets**.

## Le temps d'un projet

Le temps d'un projet est la **somme du temps de ses tâches**, au total et par mois. C'est sur lui que s'appuiera la
facturation par projet. Voir [Le temps passé](#modal-tma.temps).

## La liste des tâches

**Support › Tâches projet** range les tâches par projet ; le filtre **Projet** n'en montre qu'un.
