# La mise en forme du texte

Les descriptions et les messages acceptent : **gras**, *italique*, souligné, barré, liens, titres (dans les
descriptions), listes à puces et numérotées, citations, blocs de **code**.

Pour une erreur, un extrait de journal ou une requête, le **bloc de code** garde les espaces et les retours à la ligne.

## Ce qui est retiré

Tout est nettoyé à l'enregistrement : les scripts, le contenu actif, les cadres intégrés (iframe), les styles, et les
liens autres que web (`https://`) ou courriel (`mailto:`). Ce qui est collé depuis un autre logiciel peut donc
perdre une partie de sa mise en forme.

Pour une image, utilisez une **pièce jointe** (voir [Les pièces jointes](#modal-tma.chronologie.fichiers)).
