# La pause et sa reprise

**Mettre en pause** suspend un ticket nouveau ou en cours **jusqu'à une date** : un correctif à livrer avec la prochaine version,
un fournisseur qui doit répondre, une période de fermeture…

- **Reprise le** : obligatoire, dans le futur. Le ticket reprend **tout seul** ce jour-là (vérifié tous les quarts
  d'heure) et repasse **En cours**.
- **Motif** : facultatif ; il reste dans l'historique.

Le Support peut **Reprendre** avant la date. Pendant la pause, le ticket attend toujours le Support ; le jour de la
reprise, il apparaît dans le récapitulatif quotidien de son contact au Support (« Reprennent aujourd'hui »).
