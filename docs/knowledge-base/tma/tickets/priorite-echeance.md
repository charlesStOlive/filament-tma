# La priorité

**Basse**, **Normale** (par défaut), **Haute** ou **Urgente**. Elle aide l'équipe qui traite à choisir par quoi
commencer : elle s'affiche dans la liste, qui peut être filtrée et triée par priorité. Elle ne déclenche rien
d'automatique.

Le demandeur la choisit en écrivant sa demande ; ensuite, seule l'équipe qui traite peut la changer, quand le ticket
l'attend (voir [Qui doit agir ?](#modal-tma.comprendre.la-main)).
