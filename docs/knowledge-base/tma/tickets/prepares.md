# Les tickets préparés par le centre de service

Dans le centre de service, **Nouvelle demande** prépare un ticket **pour un client**, au nom de l'un de ses
utilisateurs : une maintenance annuelle, une anomalie repérée par l'équipe…

- **Application du client** : où le ticket apparaîtra.
- **Demandeur** : choisi parmi les utilisateurs de cette application qui ont accès au centre de service (la liste est
  demandée à l'application, et gardée une heure).
- **Publication programmée** : facultative.

## Invisible jusqu'à sa publication

Tant qu'il est en **brouillon**, le ticket n'existe que dans le centre de service. Il apparaît chez le client :

- tout de suite, avec **Publier chez le client** ;
- ou à la date de **publication programmée** (vérifiée toutes les cinq minutes).

Il arrive alors **Soumis**, au nom du demandeur choisi, qui peut en être prévenu (si l'application l'a réglé ainsi).
Ensuite, c'est un ticket comme les autres.
