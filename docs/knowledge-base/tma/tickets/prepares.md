# Les tickets préparés par le Support

Chez le Support, **Nouvelle demande** prépare un ticket **pour un client**, au nom de l'un de ses
utilisateurs : une maintenance annuelle, une anomalie repérée par l'équipe…

- **Application du client** : où le ticket apparaîtra.
- **Demandeur** : choisi parmi les utilisateurs de cette application qui ont accès au Support (la liste est
  demandée à l'application, et gardée une heure).
- **Publication programmée** : facultative.

## Invisible jusqu'à sa publication

Tant qu'il est en **brouillon**, le ticket n'existe que chez le Support. Il apparaît chez le client :

- tout de suite, avec **Publier chez EDM** ;
- ou à la date de **publication programmée** (vérifiée toutes les cinq minutes).

Il arrive alors **Nouveau**, au nom du demandeur choisi, qui peut en être prévenu (si l'application l'a réglé ainsi).
Ensuite, c'est un ticket comme les autres.
