# Résolu : confirmer ou renvoyer

Tout se fait dans la zone **Nouveau message**, sous l'historique : le texte écrit accompagne le passage.

## Marquer comme résolu (le Support)

Le travail est fait, dès la demande arrivée ou plus tard. **Ce qui a été fait** (facultatif) s'ajoute à l'historique, et le ticket, **Résolu**, attend
le demandeur.

## Confirmer et clore (le demandeur)

Le résultat convient : le ticket est **Clos**, avec le mot du demandeur s'il en écrit un. C'est l'état qui permet de le
facturer entièrement.

## Retour au Support (le demandeur)

Le résultat ne convient pas : **Ce qui ne va pas** est obligatoire, s'ajoute à l'historique, et le ticket revient
**En cours**, chez le Support.

Seul le demandeur confirme ou renvoie ; un autre destinataire principal peut d'abord **prendre la main** (voir
[Prendre la main](#modal-tma.tickets.question-reponse)).

## Sans confirmation

Le Support, avec le droit, peut **forcer la clôture** (voir [Les forçages](#modal-tma.tickets.forcages)). Et sans
aucune activité pendant 28 jours, le ticket est clos automatiquement (voir
[La clôture automatique](#modal-tma.tickets.cloture-automatique)).
