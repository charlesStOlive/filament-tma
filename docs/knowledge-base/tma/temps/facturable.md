# Temps facturable

**Facturable** (coché par défaut) : ce temps sera facturé au client, et il **consomme son forfait** (voir
[Les forfaits](#modal-tma.forfaits)).

Décochez pour un temps offert, une reprise d'erreur, une réunion interne : il reste compté dans le temps passé, mais
ni facturé ni décompté du forfait.

## Une saisie facturée est verrouillée

Une fois **rattachée à une facture**, une saisie ne se modifie plus et ne se supprime plus (le cadenas dans la liste),
quel que soit l'état de la facture. Il faut d'abord défaire le rattachement.

## Si le forfait est épuisé

Selon le réglage de l'application, une saisie facturable qui ferait **dépasser** le forfait est soit acceptée (et le
dépassement signalé), soit refusée.
